# ทุ่งฝึกหัด: Phase 0

เกม 3D บนเว็บที่ใช้ระบบเกมแบบ RO ยุคคลาสสิก (stat 6 ตัว, Base/Job Level, คลิกตีอัตโนมัติตาม ASPD, HIT/FLEE) แต่โลก ตัวละคร และมอนสเตอร์ออกแบบเองทั้งหมด

Phase 0 คือ **Novice เล่นคนเดียวในเบราว์เซอร์** ใช้พิสูจน์ว่าการต่อสู้สนุกก่อนเริ่มทำ server

## เริ่มรัน

```bash
npm install
npm run dev        # เปิด http://localhost:5173
```

- บน macOS ดับเบิลคลิก `start-game.command` ได้เลย สคริปต์จะติดตั้ง dependencies ให้ถ้ายังไม่มี แล้วเปิดเกมในเบราว์เซอร์ (ครั้งแรกถ้า macOS เตือน ให้คลิกขวาแล้วเลือก Open)
- ต้องใช้ Node.js 20.19 หรือ 22.12 ขึ้นไป
- อยากเลเวลเร็วตอนทดสอบ ให้เติม `?rate=10` หรือ `#x10` ท้าย URL (EXP x10, สูงสุด x50)
- เซฟอยู่ใน localStorage ของเบราว์เซอร์ ถ้าอยากเริ่มใหม่ กด `H` แล้วเลือก "ลบตัวละคร"
- `npm run build` จะ typecheck แล้ว build ลง `dist/`

## วิธีเล่น

| ปุ่ม | ทำอะไร |
| --- | --- |
| คลิกซ้ายที่พื้น | เดิน (กดค้างไว้เพื่อเดินตามเมาส์) |
| คลิกมอนสเตอร์ | เดินเข้าไปตีอัตโนมัติจนตาย |
| คลิก NPC / ศิลาบันทึก | คุย |
| คลิกขวาลาก, `←` `→` | หมุนกล้อง |
| ล้อเมาส์, `↑` `↓` | ซูม |
| `A` / `S` / `Q` / `H` | หน้าต่างสถานะ / สกิล / เควสต์ / วิธีเล่น |
| `1` `2` `3` `4` | ปฐมพยาบาล / แกล้งตาย / นั่งพัก / อีโมต |
| `Esc` | ปิดหน้าต่าง |

## มีอะไรใน Phase 0

- สร้างตัวละคร: ทุกค่าเริ่มที่ 1 แจก 45 แต้ม แต่ละค่าลงได้ไม่เกิน 10
- Novice: Job Lv สูงสุด 10, ตายแล้วไม่เสีย EXP, ถือมีดฝึกหัด
- แต้ม stat ได้ `floor(BaseLv/5)+3` ต่อเลเวล ค่าอัป stat = `floor((x−1)/10)+2`
- Basic Training Lv 1–9: ได้ 1 แต้มต่อ Job Lv ดังนั้น Job Lv 10 จะได้ Lv 9 พอดี ในเฟสนี้ใช้ได้จริงคือ อีโมต (Lv 2), นั่งพัก (Lv 3), ตั้งจุดเกิด (Lv 8) และปลดเงื่อนไขเปลี่ยนอาชีพ (Lv 9)
- เควสต์ NPC: พยาบาลสอน **ปฐมพยาบาล** (ปราบม็อสบอล 5 ตัว) และพรานเฒ่าสอน **แกล้งตาย** (ปราบจิ้งจกใบไม้ 3 ตัว รับได้ตั้งแต่ Base Lv 5)
- ผู้ดูแลอาชีพตรวจเงื่อนไขเปลี่ยนอาชีพ ส่วนการเปลี่ยนอาชีพจริงมาใน Phase 2
- ทุ่งฝึกหัดมีมอน 5 ชนิด: ม็อสบอล, ด้วงกรวด (DEF สูง), มอดฝุ่น (FLEE สูง), จิ้งจกใบไม้ (ตีก่อน) และบอสย่อยราชินีด้วงกรวด (เกิดใหม่ทุก 30 นาที)
- มอนมี AI ครบ: เดินสุ่ม, สวนกลับเมื่อโดนตี, ตัวที่ตีก่อนจะไล่ตามเมื่อเข้าใกล้, ไล่ไกลเกินไปจะกลับฐาน, ตายแล้วเกิดใหม่
- ตัวเลขดาเมจ, Miss, คริติคอล, เอฟเฟกต์เลเวลอัป, หลอด HP/SP ใต้ตัวละคร, หน้าจอหมดสติ

## โครงสร้างโค้ด

```
src/
  shared/              กติกาเกมล้วน ๆ ไม่มี DOM หรือ Three.js
    types.ts           type ของ stat, ตัวละคร, มอน, สกิล
    formulas.ts        สูตร ATK/HIT/FLEE/CRIT/ASPD/HP, ดาเมจ, ตาราง EXP
    progression.ts     สร้างตัว, ได้ EXP/เลเวลอัป, ลงแต้ม, เควสต์
    data/              jobs, skills, monsters, items, quests, maps
  game/                ฝั่งเบราว์เซอร์ (Three.js)
    Game.ts            game loop, input, AI มอน, การต่อสู้, NPC, เซฟ
    entities.ts        Player / Monster / Npc และแอนิเมชัน
    models.ts          โมเดล low-poly ที่สร้างจากโค้ด
    world.ts           พื้น ต้นไม้ หิน ดอกไม้ หมู่บ้าน
    fx.ts              ตัวเลขลอย, ป้ายชื่อ, เอฟเฟกต์
  ui/                  React สำหรับ HUD และหน้าต่างต่าง ๆ
```

`src/shared` ตั้งใจให้ไม่ผูกกับเบราว์เซอร์ พอถึง Phase 1 จะย้ายไปเป็น `packages/shared` แล้วให้ server (Colyseus) ใช้สูตรชุดเดียวกันคำนวณการต่อสู้

## ปรับสมดุล

- ตัวเลขมอนอยู่ที่ `src/shared/data/monsters.ts` (HP, ATK, DEF, HIT, FLEE, EXP, เวลาเกิดใหม่)
- จำนวนและพื้นที่เกิดของมอนอยู่ที่ `src/shared/data/maps.ts`
- สูตรทั้งหมด รวมถึงแต้มตอนสร้างตัวและตาราง EXP อยู่ที่ `src/shared/formulas.ts`

## Phase ถัดไป

1. **Phase 1:** multiplayer 1 แผนที่, ล็อกอิน, เซฟลง PostgreSQL
2. **Phase 2:** อาชีพที่ 1 ทั้ง 6 สาย, ไอเทม, ของดรอป, เควสต์เปลี่ยนอาชีพ
3. **Phase 3:** ปาร์ตี้, การ์ด, ตั้งร้าน, แผนที่เพิ่ม

โมเดลใน `models.ts` เปลี่ยนเป็นไฟล์ glTF จาก Blender ได้ทีละตัว ขอแค่ให้มีจุดหมุน (root/hips/แขน/ขา) ที่ `entities.ts` ใช้ทำแอนิเมชัน
